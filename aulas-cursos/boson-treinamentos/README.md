# Bóson Treinamentos — Segurança e Criptografia

Anotações e exercícios práticos feitos acompanhando a playlist **"Segurança e Criptografia"** do canal Bóson Treinamentos no YouTube.

## Conteúdo

- [`autenticacao-ssh/`](./autenticacao-ssh) — exercícios sobre autenticação via chaves SSH
- [`criptografar-arquivo/`](./criptografar-arquivo) — exercícios de criptografia de arquivos

## Metodologia

A cada vídeo assistido, resolvo três exercícios práticos em Python (fácil, médio e difícil) sobre o tema abordado, sempre tentando resolver por conta própria antes de checar a solução.

## Tópicos já estudados

- Criptografia de chave pública e privada
- Funções hash
- Operações bitwise
- Autenticação SSH
